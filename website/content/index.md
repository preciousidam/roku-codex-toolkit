## Two focused plugins

**Roku Device Toolkit** provides bounded device operations, developer-mode tooling, and
evidence-aware JSON flows. **Roku Engineering** provides causal log analysis, accessibility review,
and release validation.

The toolkit complements Roku editors, debuggers, developer services, and certification workflows.
It does not replace them, and it never treats a completed command or screenshot capture as proof
that a UI is correct.

## Start safely

Begin with the host-only installation checks. A physical Roku is required only when you move from
package and scenario validation to real device queries or actions.
