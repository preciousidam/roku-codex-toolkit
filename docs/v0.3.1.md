# v0.3.1 release notes

v0.3.1 is a documentation-discoverability patch release. It does not change Roku device behavior,
MCP tools, flow semantics, credential handling, or the Python and Node.js architecture boundary.

## Included

- Link the hosted documentation portal, plugin guide, and npm package prominently from the README.
- Point npm package homepage metadata at the hosted documentation portal.
- Link the hosted plugin guide directly from the repository's tooling overview while retaining the
  canonical Markdown source link.
- Add regression coverage for the public documentation URLs.
- Publish the release notes in the documentation portal.

## Validation boundary

- Run the complete Node and Python repository validation.
- Validate the packed npm inventory and CLI package.
- Build and validate the static documentation portal.
- Run the GitHub Actions matrix on macOS, Linux, and Windows.
- Run the trusted npm publication checks and post-publication smoke matrix after explicit release
  approval.

Physical Roku validation is not required for this patch because no device-facing code or behavior
changed. Existing evidence boundaries remain unchanged: successful commands and screenshots alone
do not prove that the Roku UI is correct.
